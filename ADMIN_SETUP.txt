RealCash update notes
=====================

Admin Referral Code (initial):
REALCASH-ADMIN-2026

Admin login now requires:
1. Existing Admin ID
2. Admin Referral Code

The Admin Referral Code can be changed from:
Admin Panel -> Admin Referral Code

Ads/Video reward:
- Default: 30 Coins
- Admin Panel -> Ads / Video Reward
- The new value is stored in settings/exchangeRate.adReward

Withdrawals:
- Currency shown to users: MMK
- Payment methods: Wave Money / KPay
- User must provide account name and phone number
- Minimum withdrawal: 1,000 MMK
- Balance is reserved when a request is submitted.
- Approved: balance remains deducted.
- Rejected: MMK is automatically returned to the user.

IMPORTANT:
Firestore security still requires the real Firebase Auth UID of the admin
to have an active document at admins/{uid}. The Admin ID field is the
existing app-level admin ID and is not a substitute for Firestore security.
