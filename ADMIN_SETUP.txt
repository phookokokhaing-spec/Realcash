REALCASH SECURE ADMIN SETUP v3

1. Firebase Console -> Authentication -> Sign-in method
   Enable:
   - Anonymous
   - Email/Password

2. Authentication -> Users -> Add user
   Create the Admin email/password account.

3. Copy that Admin user's UID.

4. Firestore Database -> Data
   Create collection: admins
   Document ID: paste the Admin UID
   Fields:
     active = true   (Boolean)

5. Firestore Database -> Rules
   Replace the current rules with firestore.rules from this package and Publish.

6. Open the app. Tap the tiny Admin trigger and enter the Firebase Admin
   email/password. The Admin panel will load users only after the UID is
   verified against admins/{UID}.

IMPORTANT
- Do NOT use allow read, write: if true;
- The old HTML-only password is no longer the authority for admin access.
- New user records are bound to Firebase Anonymous Auth UID.
- Existing user documents created before this secure version may not contain
  authUid. Those records need a controlled migration before their owners can
  update them under the new rules. Do not expose a public claim rule just to
  make this work, because that could let another user take over a balance.
